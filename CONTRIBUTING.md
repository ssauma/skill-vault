# Contributing

Thank you for improving Skill Vault.

- Search existing issues and pull requests before proposing a change.
- Open an issue first for transaction semantics, discovery thresholds, or host-support changes.
- Preserve original skill paths, exact invocation names, explicit approval, and complete rollback.
- Keep npm, Claude Code, and Codex versions aligned.
- Keep English and Korean documentation semantically aligned.

Use Node.js 20 or newer and run:

```bash
npm test
```

Pull requests should describe user-visible behavior, verification performed, and remaining limitations. Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), and report vulnerabilities through [SECURITY.md](SECURITY.md).
