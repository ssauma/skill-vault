# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

Do not open a public issue with exploit details, credentials, configuration contents, private skill instructions, or personal data.

Use GitHub's private vulnerability reporting flow:

<https://github.com/ssauma/skill-vault/security/advisories/new>

Include the affected version, impact, reproduction steps, and suggested mitigation. The maintainer will acknowledge and coordinate disclosure through the advisory.
